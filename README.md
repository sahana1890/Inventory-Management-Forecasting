# Inventory-Management-Forecasting-Anal# Inventory Management & Forecasting Analysis

## Project Overview

This project analyzes retail inventory data using Microsoft Excel and Power BI 
to evaluate inventory performance, demand patterns, and stock availability.

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- Pivot Tables
- Data Visualization
- Forecasting

## Key Analysis

- Inventory Turnover
- Fill Rate
- Stock Availability
- Inventory Gap
- ABC Classification
- Demand Forecasting

## Dashboard

An interactive Power BI dashboard was created to monitor inventory performance 
and identify low-stock, overstock, and high-value products.

## Objective

The objective was to analyze inventory data and generate insights that can 
support better inventory management and operational decision-making.
